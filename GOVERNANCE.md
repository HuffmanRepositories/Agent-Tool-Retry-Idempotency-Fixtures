# Governance

This repository is a small, maintainer-led, open fixture corpus.

- Maintainer review is required before merging changes.
- Fixture format and expected outcomes are versioned in the repository.
- Draft fixtures may change as assumptions are clarified.
- Reviewers should flag protocol-specific behavior and missing assumptions.
- No fixture constitutes certification or a normative specification.
- Issues and pull requests are welcome; disagreement should be documented constructively.

The project makes no claim that its examples exhaust retry/idempotency failure modes.
